# Parrot Firmware Flasher

Parrot Firmware Flasher covers installing, updating and recovering firmware on Parrot devices.

## Scope

- First-time firmware installation and device setup.
- Firmware updates.
- Recovery from interrupted or unsuccessful flashing.

## Current status

This repository provides public issue tracking and product planning. Product source code is not currently published here.

For Bluetooth pairing, call audio or on-device behavior after installation, use the [Firmware tracker](https://github.com/ParrotVoiceApp/Firmware).
